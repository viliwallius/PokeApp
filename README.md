Projektin ajaminen Windowsilla
------------------

1. Pura ZIP-tiedosto PokeApp-main

2. Mene kansioon WOH_Final_Project(OIKEA) -> klikkaa hiiren oikealla tyhjää kohtaa kansiossa ja valitse "Avaa päätteessä"

3. Lataa riippuvuudet kirjoittamalla päätteeseen yksi kerrallaan npm install ja npm install bootstrap

4. Kun riippuvuudet on ladattu, käynnistä kehityspalvelin kirjoittamalla päätteeseen npm run dev. Tämän jälkeen avautuva osote näkyy päätteessä (esim. http://localhost:5173). Avaa se selaimeen.

Sovellus on konfiguroitu julkaistavaksi GitHub Pagesiin. Halutessasi voit päivittää tuotantoversiota komennolla npm run deploy.
